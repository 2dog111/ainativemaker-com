## Две языковые версии (с 21.09.2026)

Главная `/` — английская (`src/index.en.html`, `src/ai.en.html`), русская
заморожена и живёт под `/ru/` (`src/index.html`, `src/ai.html`). Дневник один:
русский текст дословный, английский — перевод в `src/content/diary-en/*.json`
(порции), сливается в `src/content/diary.en.json` при `npm run build`. Ключ —
id записи, число абзацев обязано совпадать с оригиналом (сборка падает иначе).
Новые записи с 21.09.2026 добавляются только в английскую версию:
`src/content/chat-diary-selection.en.js` → `npm run import:chat-diary:en` →
перевод нового id в `diary-en/batch-NN.json`. Русский отбор и
`chat-diary.generated.json` не трогать. Название дневника везде —
«Дневник AI-native предпринимателя» / «AI-Native Founder's Diary»
(решение владельца 21.09.2026, прежнее «вайб-кодеров» снято).

Уточнение владельца 04.10.2026: тексты главных страниц `/` и `/ru/` обновлены для удаления блока о комьюнити, новые записи дневника остаются только в английской версии. Опубликованные записи можно исключать списком `src/content/journal-exclusions.js`, исходные корпуса сохраняются. Несколько записей одного дня визуально соединяются без правки их абзацев и ID. Для новых записей не смягчать лексику; переводить с сохранением смысла, исправляя только грамматику и пунктуацию исходных текстов при необходимости.
Форма и ошибки API локализованы по `lang` страницы; заявка хранит `lang`.

## Дневник вайб-кодеров

Две части одной ленты:

- канал — `src/content/diary.generated.json`, защищённый файл, руками не трогать;
- закрытый чат — `src/content/chat-diary-selection.js` (список отбора) и
  `src/content/chat-diary.generated.json` (текст, генерируется импортом).

Навигация по дневнику — только месяцы, закреплена сверху.

Пополнение свежими сообщениями (владелец просил примерно раз в неделю):

1. свежие сообщения уже в корпусе Антона: он докачивается из панели `tgwebparser`
   раз в сутки (`~/Documents/ChatGPT/Anton-All-Text-30-08-26/CHAT-EVENTS.md`);
   импорт читает его реестр `проверка-и-реестры/chat-events/events.jsonl`.
   Посты ботов (пульс дня, донаты, турниры, Астрочка) там помечены `machine_post`;
2. найти подходящие блоки по теме
   «путь вайб-кодера»: рефлексия о работе с моделями, ошибки, доведение до
   запуска. Новости моделей, дайджесты и бытовое — не брать;
3. дописать их id и короткую причину в `chat-diary-selection.en.js` (русская
   версия заморожена, новое — только в английскую): для корпуса это `unit_id`
   из `units.json`, для свежей выгрузки — `tgw-<msg_id>`; хвост чужого разговора
   в склеенном блоке отрезается полем `endMsgId`;
4. `npm run import:chat-diary:en`, перевести новые записи в
   `src/content/diary-en/batch-NN.json` (тот же id, то же число абзацев);
5. `npm run build && npm run check && npm test`.

Текст записей не редактировать никогда: ни Anton, ни Gary, ни Bovari, ни любой
другой текстовый скилл к хронологии не применять.
